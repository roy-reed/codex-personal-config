# codex-personal-config

这是个人 Codex 配置的轻量仓库入口，用于保存适合长期版本化、可审计和可恢复的配置说明。

## 当前状态

当前仓库仅保留基础说明，尚未据此声明任何具体本地配置已经完成同步或自动部署。后续若加入配置文件、同步脚本或恢复工具，应逐项说明来源、作用范围和验证方式。

## 安全边界

- 不提交 API Key、访问令牌、Cookie、SSH 私钥、证书、`.env`、浏览器登录状态或其他凭据。
- 不提交原始个人资料、对话记录、任务历史、附件或不适合长期保存的临时上下文。
- 不提交未公开研究材料、敏感参数、项目代号、人员信息或其他受限内容。
- 私有 GitHub 仓库仍属于第三方存储；新增内容前应重新判断是否确有跨设备保存和版本审计价值。

## 维护约定

- 说明和注释优先使用中文；命令、参数、路径和标准技术名词保持原样，避免翻译导致歧义。
- 修改配置时尽量保持单一目标、小范围提交，并写明变更原因。
- 重要配置变更应保留可验证依据；计划、说明或模型输出本身不视为验收结果。
- 不在未经确认的情况下自动覆盖本地权威配置，也不把远端仓库状态推断为本机当前状态。
