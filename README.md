# codex-personal-config

这是一个面向个人配置片段的公开、可迁移仓库。它只接收经过审查、能够跨设备复用的通用配置、示例和维护文档；不把个人账户状态、凭据、浏览器资料、工作区原文或研究材料作为开源内容。

## 当前状态

当前仓库从空白基线开始维护，尚未约定具体配置格式，也没有把本机的完整配置目录直接复制进来。后续新增内容必须先明确用途、适用平台和敏感信息边界。

## 建议结构

```text
config/       可公开复用的配置片段或模板
docs/         平台差异、迁移说明和维护记录
scripts/      可重复运行的检查与转换工具
examples/     脱敏后的最小示例
```

配置片段应优先使用相对路径、环境变量和平台检测，不要写死用户目录、盘符、代理端口或本机服务地址。需要密钥的配置只提供变量名和示例占位符，不提交真实值。

## 维护流程

1. 先在 Issue 或变更说明中写清用途、输入、输出和支持平台。
2. 添加最小可运行示例或检查命令，并保留原有配置格式。
3. 执行 `git diff --check`，检查路径、凭据和个人信息。
4. 在 Windows、Linux 或 macOS 上验证与本次变更相关的路径分支。
5. 提交前再次确认仓库中没有账户状态、任务历史和未公开材料。

## 公开边界

本仓库公开可见。令牌、Cookie、私钥、证书、`.env`、浏览器数据、完整个人画像、研究计划和单位/项目敏感信息均不属于仓库内容。疑似误提交时，先撤销凭据，再通过私下渠道报告。
